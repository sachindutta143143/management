The Data Backup page downloads one .xlsx workbook.

Product List:
- One product per row.
- Dedicated DP Price column.
- DP Price values are read from saved product HTML cells marked dp-price-cell.
- Product HTML is also preserved in Product HTML Backup and Full Data Snapshot.
- Blank DP Price cells remain blank if no DP value was saved; values are never guessed.

Registers:
- Credit Register and Supply Register are separate worksheets, sourced from the same combined credit_supply_register database table.
- Installment Register is ONE worksheet containing customer details, every installment schedule row, and all payment history columns.
- Others Register, Customers, Quotation Settings, Quotation Content, Legacy App Data, Browser Backup and Full Data Snapshot are retained.

Browser-saved product data is preferred when present so unsynced edits are not missed.
The backup endpoint is read-only. No database tables or business records are deleted, cleared, or modified.
The existing JSON API endpoint remains available for compatibility.
